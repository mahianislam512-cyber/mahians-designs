# Mahians Designs — Portfolio + Admin Panel

Glassmorphism portfolio website with a built-in admin panel for uploading photos & videos.

## Quick start
```
npm install
npm start
```
- Website:     http://localhost:8080
- Admin Panel: http://localhost:8080/admin  (default: admin / mahian123 — CHANGE IT)

## Full run & deploy guide (Bangla)
See **DEPLOY-GUIDE.md** — covers local run, Render, Railway, VPS, Docker, custom domain.

## Env vars
| Var | Default |
|---|---|
| ADMIN_USER | admin |
| ADMIN_PASS | mahian123 |
| PORT | 8080 |
| DATA_DIR | ./data (content.json + uploads/) |

## Backup
Copy the `data/` folder — it contains everything (content + uploaded files).
